## Static vs. Dynamic QR Codes — Which One Do You Actually Need?

This is the distinction most free generators skip, and it's the one that matters most once you've printed anything.

- **Static QR codes** encode the destination directly into the code itself. They're permanent — if the link breaks or changes, the printed code is now useless.
- **Dynamic QR codes** point to a short redirect link you control. You can change the destination anytime without reprinting, and you get scan data (when, how often, roughly where from) that static codes can't give you.

<StepCard number="1" title="Pick Static for One-Off, Unchanging Content">
A WiFi password, a fixed phone number, or a file that will never move are all good candidates for a static code — there's nothing to update later.
</StepCard>

<StepCard number="2" title="Pick Dynamic for Anything You Might Need to Change">
Menus, promotions, table codes, and product links are all things that shift over time. A dynamic code lets the printed QR code stay exactly the same while what it points to changes behind the scenes.
</StepCard>

## Big QR Codes for Print and Signage

A code that looks fine on a phone screen can turn into a blurry mess blown up for a storefront window or event banner. For anything large-format:

- **Export as SVG**, which scales to any size without losing sharpness — banners, window clings, posters
- **Increase the error-correction level** before enlarging, so the code still scans cleanly even if part of it gets covered by a logo or slight print imperfection
- **Test the printed size at actual distance** — a code meant to be scanned from across a room needs to be noticeably larger than one sitting on a table
