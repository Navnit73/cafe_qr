## How the Wi-Fi QR Code Payload Schema Works

Wi-Fi QR codes adhere to the MeCard Wi-Fi configuration specification supported natively by iOS (iOS 11+) and Android (Android 9+):

```
WIFI:S:<SSID>;T:<WPA|WEP|nopass>;P:<Password>;H:<true|false>;;
```

- **`S:` (Service Set Identifier)**: The exact network name broadcast by your router (case-sensitive).
- **`T:` (Authentication Type)**: `WPA` (standard for WPA, WPA2, and WPA3), `WEP`, or `nopass` for open guest networks.
- **`P:` (Pre-Shared Key / Password)**: The Wi-Fi security passphrase (case-sensitive).
- **`H:` (Hidden Network)**: Set to `true` if your router does not broadcast its SSID beacon.
